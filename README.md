# MD Asraful Rahaman — Portfolio

This site is a dependency-free, single-page portfolio for GitHub Pages. `index.html` contains all styling; the photo is the only local asset.

## Publish on GitHub Pages

1. Create a new GitHub repository named `portfolio` (or any name you prefer).
2. Upload the contents of this folder — keep `index.html` at the top level and the `assets` folder beside it.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main`, then choose `/(root)` and press **Save**.
5. GitHub will publish the site at `https://YOUR-USERNAME.github.io/portfolio/` within a few minutes.

Before publishing, replace the clearly highlighted placeholders in `index.html` with your project details, official certification badge files/links, Medium profile URL, and LinkedIn recommendations. No external libraries or build step are required.
